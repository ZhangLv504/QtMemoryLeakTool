# QtMemTracker

专为 Qt/C++ 开发者设计的轻量级内存泄漏检测与对象树拓扑分析工具。本项目使用 C++17 标准和 Qt Widgets 开发，旨在直接解决实际业务中因 `QObject` 父子关系管理不当或原始指针遗漏导致的内存泄漏问题。

## 核心特性

1. **精准定位泄漏源**
   - 拦截全局动态内存分配。
   - 自动记录未释放内存的产生位置（精确到 `__FILE__` 与 `__LINE__`）。
   - 将泄漏快照安全持久化到本地日志文件。

2. **Qt 对象树可视化**
   - 提供基于 `QTreeView` 的对象父子关系 (Parent-Child) 可视化面板。
   - 快速排查因未正确传递 `parent` 指针而成为“游离对象”的内存泄漏隐患。
   - 强类型结合，专注于 Qt 容器与 Widget 层级的层级诊断。

## 技术栈
- **语言**：C++11/17 (利用 STL、智能指针及底层内存模型)
- **框架**：Qt 5.15.2
- **构建**：CMake / MSVC 2022
